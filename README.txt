# 臻美味自助餐 記帳機器人 — 部署說明文件

> 適用對象：想在自己的 Discord 伺服器引進此機器人的管理員

---

## 📋 事前準備

在開始之前，請確認你的電腦已安裝：

- **Python 3.10 以上**
  下載網址：https://www.python.org/downloads/
  安裝時請勾選「Add Python to PATH」

- **必要套件**
  開啟終端機（Windows 請用 PowerShell），輸入以下指令：
  ```
  pip install discord.py python-dotenv
  ```

---

## 🤖 步驟一：建立你自己的 Discord 機器人

1. 前往 [Discord Developer Portal](https://discord.com/developers/applications)，並登入你的 Discord 帳號

2. 點擊右上角「**New Application**」，輸入機器人名稱，按「Create」

3. 左側選單點「**Bot**」
   - 點「**Reset Token**」取得你的 Token（這是你機器人的密碼，**請勿外流**）
   - 複製並保存這串 Token

4. 在同一頁面往下滑，開啟以下權限：
   - ✅ **Message Content Intent**
   - ✅ **Server Members Intent**

5. 左側選單點「**OAuth2**」→「**URL Generator**」
   - Scopes 勾選：`bot`、`applications.commands`
   - Bot Permissions 勾選：`Send Messages`、`Read Message History`、`Manage Messages`
   - 複製最下方產生的 URL，用瀏覽器開啟，把機器人邀請進你的伺服器

---

## 📁 步驟二：設定程式碼

1. 將程式碼資料夾放到你想要的位置，例如：
   ```
   C:\MyBot\
   ```

2. 在資料夾裡建立一個新檔案，命名為 **`.env`**
   （注意：檔名只有 `.env`，前面沒有其他文字）

3. 用記事本開啟 `.env`，輸入以下內容：
   ```
   DISCORD_TOKEN=你的Token貼在這裡
   ```
   把「你的Token貼在這裡」換成步驟一取得的 Token，**不需要加引號**

   範例：
   ```
   DISCORD_TOKEN=MTUwNTA0MzM0NzU5OTkxNzE3MQ.XXXXXX.XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
   ```

4. 儲存並關閉記事本

---

## ▶️ 步驟三：啟動機器人

1. 開啟 PowerShell，切換到程式碼資料夾：
   ```
   cd "C:\MyBot"
   ```

2. 啟動機器人：
   ```
   py bot.py
   ```

3. 看到以下訊息代表成功：
   ```
   ✅ 斜線指令同步請求已送出
   成功登入！機器人：你的機器人名稱#XXXX
   ```

> ⚠️ 機器人需要持續運行才能使用，關掉 PowerShell 視窗機器人就會下線。

---

## ⚙️ 步驟四：初始設定（在 Discord 裡操作）

機器人啟動後，請在 Discord 伺服器裡依序完成以下設定：

### 1. 設定頻道
輸入指令：
```
/設定頻道
```
依照提示分別設定：
- **收銀台頻道**：用來顯示帳務表格的頻道
- **餐盤回收區頻道**：用來記錄結清歸檔的頻道

> 如何取得頻道 ID：在 Discord 設定裡開啟「開發者模式」，右鍵點擊頻道 → 「複製頻道 ID」

### 2. 新增成員
輸入指令：
```
/成員管理
```
點擊「新增成員」，逐一輸入要參與記帳的成員名字。

### 3. 設定 Discord 對應（選填，建議設定）
在 `/成員管理` 裡點擊「設定對應」，將每位成員的名字對應到他們的 Discord 帳號 ID。

設定完成後，`/查帳` 和 `/藍白` 等功能才能正確 @ 到對應的人。

> 如何取得用戶 ID：在 Discord 設定裡開啟「開發者模式」，右鍵點擊該用戶 → 「複製用戶 ID」

## 📖 指令一覽

| 指令 | 說明 | 權限 |
|------|------|------|
| `/記帳` | 快速新增記帳（電腦端推薦） | 所有人 |
| `/表單` | 下拉選單式記帳（手機端推薦） | 所有人 |
| `/分帳` | 多人分帳，支援自訂比例 | 所有人 |
| `/修改` | 修改特定編號的帳目 | 所有人 |
| `/刪除` | 刪除特定編號的帳目 | 所有人 |
| `/結清` | 結清兩人之間的帳務並歸檔 | 所有人 |
| `/查帳` | 查詢某人的帳務彙總 | 所有人 |
| `/藍白` | 公審本群最大欠債人 | 所有人 |
| `/重新整理` | 重新整理收銀台表格 | 所有人 |
| `/清空收銀台` | 清空收銀台頻道 | 所有人 |
| `/成員管理` | 查看成員名單（管理員可編輯） | 查看：所有人 / 編輯：管理員 |
| `/設定頻道` | 設定收銀台與餐盤回收區頻道 | 管理員 |

## ❓ 常見問題

**Q：指令打了沒有反應？**
A：斜線指令同步需要時間，請等待 3～5 分鐘後再試。

**Q：機器人在線但收不到訊息？**
A：請確認機器人在該頻道有「傳送訊息」和「讀取訊息紀錄」的權限。

**Q：關掉電腦後機器人就下線了？**
A：目前需要電腦持續運行。若想讓機器人 24 小時在線，需要將程式部署到雲端平台。

**Q：忘記 Token 怎麼辦？**
A：前往 Discord Developer Portal → 你的應用程式 → Bot → Reset Token 重新產生一個新的，並更新 `.env` 檔案。
